# Automation ribbon icon

The Automation panel uses a blue gear and amber lightning bolt to distinguish
automation tools from the former message button. The 96 × 96 RGBA PNG is in
`EasyBIM.tab/Automation.panel/Start Message.pushbutton/icon.png`. The legacy
button folder name is retained; the visible panel and button both say Automation.

Generated with the built-in image generation tool, then downsampled with
ImageMagick for the ribbon while preserving transparency.

## Generation prompt

Use case: logo-brand. Create one production-ready square PNG toolbar icon for
an Autodesk Revit automation button. Subject: a bold simple blue gear with a
crisp warm amber lightning bolt centered inside it, conveying automated tasks.
Flat vector-like appearance, strong readable silhouette at 32px ribbon display,
generous thick forms, restrained two-color palette, no fine details, no gradients,
no shadows, no border, no letters, no text, no envelope or speech bubble. Center
the gear and bolt with approximately 8 percent transparent padding. Genuinely
transparent alpha background. Single icon only.
